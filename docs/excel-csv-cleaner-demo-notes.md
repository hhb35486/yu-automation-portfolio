# Excel / CSV Cleaner Demo Notes

## Demo Purpose

This demo shows a narrow report table cleaner workflow: turn a messy CSV table into a cleaner CSV that can be pasted into a report or used for light follow-up processing.

It is a portfolio / lead magnet feasibility demo. It is not a paid product, SaaS, formal data service, or production data processing tool.

## Synthetic Sample Only

The demo uses synthetic sample CSV data only:

- Generic departments
- Generic report items
- Generic amounts
- Generic statuses

It does not use real people, real accounts, real orders, company internal data, insurance data, financial records, medical records, contact details, or identity documents.

## Privacy Boundaries

- Do not use real customer data in the demo.
- Do not use company internal data in the demo.
- Do not use sensitive insurance, financial, medical, identity, or contact information.
- The page does not provide a file upload control.
- The page does not send data to a server.
- The page does not connect to an API, LLM, crawler, analytics service, or tracking tool.
- Cleaned output still needs human review.

## What It Does

- Loads a built-in synthetic sample CSV
- Removes empty rows
- Trims leading and trailing whitespace
- Normalizes headers into report-friendly CSV column names
- Detects duplicate rows
- Shows before / after tables
- Shows a small cleaning summary
- Copies the cleaned CSV
- Downloads the cleaned CSV sample

## What It Does Not Do

- It does not process uploaded files.
- It does not validate business correctness.
- It does not handle every CSV edge case.
- It does not replace manual review.
- It does not store data.
- It does not claim production readiness.
