# Yu Automation Portfolio

這是一個個人接案作品集網站，定位為 AI 協作自動化、資料整理與內部工具建置。

## 網站內容

- Hero 首頁介紹
- 服務項目
- 作品集展示
- 合作流程
- 聯絡方式
- SVG Logo / favicon

## 技術使用

- HTML
- CSS
- JavaScript
- GSAP CDN
- IntersectionObserver
- Responsive Web Design

## 專案特色

- 純靜態網站
- 不需後端
- 不需 npm install
- 支援手機版 RWD
- 支援 prefers-reduced-motion
- GSAP 未載入時仍可正常顯示
- 無真實公司、保險、客戶或敏感資料

## 本機開啟方式

方式一：直接開啟

```bash
open index.html
```

方式二：本機伺服器

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

## 專案檔案結構

```text

backups/
```
